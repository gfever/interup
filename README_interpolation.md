Инструкция и краткое описание

Файлы:
- `kaggle_video_interpolation_notebook.ipynb` — ноутбук для Kaggle с ячейками для интерполяции видео до 60 FPS.

Как использовать:
1. Откройте ноутбук в Kaggle (загрузите его в ваш Kernel).\n2. Загрузите видео через Data -> Add or upload your data в папку `/kaggle/working/input/` или поместите файл в `kaggle/input` как Dataset.\n3. Выполните ячейки сверху вниз.\n
Примечание по RIFE: требует GPU и времени; используйте только при наличии GPU в сессии.
